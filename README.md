# Portafolio Profesional — Sara Sandoval

Bienvenido/a a mi portafolio web profesional...Este espacio ha sido diseñado y desarrollado para presentar mis proyectos de desarrollo de software, mi perfil profesional, mis habilidades técnicas y mis canales de contacto.

---

## Tecnologías Utilizadas

* **HTML5**: Estructuración semántica del sitio web.
* **CSS3**: Variables CSS, paleta de colores personalizada (Terracota, Lila y Crema), efectos visuales y diseño 100% responsivo.
* **JavaScript (ES6+)**: Interactividad y comportamiento fluido de la interfaz.
* **Web3Forms**: Integración para el envío directo de mensajes a mi correo electrónico personal.
* **Font Awesome & Google Fonts**: Iconografía y tipografías (`Poppins` e `Inter`).
